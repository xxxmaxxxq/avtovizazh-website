# АвтоВизаж — сайт автосервиса

Одностраничный сайт кузовного автосервиса «АвтоВизаж»: кузовной ремонт,
малярные работы, восстановление геометрии, 3 сервисных адреса.
Есть форма заявки и быстрый звонок.

## Стек

TanStack Start (React + TypeScript) · Vite · Tailwind CSS · Bun

## Разработка

```sh
bun install
bun run dev
```

Сборка:

```sh
bun run build
```

## Структура

| Путь | Что там |
|---|---|
| `src/routes/` | Маршруты приложения |
| `src/components/site/` | Секции лендинга: Hero, Sections, формы |
| `src/lib/site-data.ts` | Телефон, адреса, тексты — правки контента здесь |
| `src/assets/` | Изображения |

## Контакты в коде

Телефон и адреса в `src/lib/site-data.ts` заменены на демо-значения — репозиторий
публичный. Реальные подставляются при деплое.
